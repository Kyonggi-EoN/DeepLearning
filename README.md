# DeepLearning

2026년, 가장 큰 관심사는 AI입니다.   
단순히 AI를 사용하는 것을 넘어서, AI의 구조를 파악하고 실제로 만드는 것을 목적으로 합니다.

## 왜 배우는가?

우리 전공은 나노반도체고, 전자공학입니다. AI가 아닙니다.   
그런데 왜 AI를 배워야 할까요?

취직을 한다고 생각을 해봅시다.

통신 회사에 갔습니다. 5G 신호가 건물에 부딪혀 왜곡됩니다.   
기존 알고리즘으로는 복원이 안 됩니다. **AI가 복원합니다.** 이미 현장에서 쓰고 있습니다.

반도체 회사에 갔습니다. 우리 전공 한가운데입니다.
- 신소재를 개발해야 합니다. 후보 물질이 수만 가지입니다. 다 실험할 수 없습니다. **AI가 물성을 예측합니다.**
- 웨이퍼에서 불량이 나옵니다. 사람 눈으로는 하루 수만 장을 볼 수 없습니다. **AI가 불량 패턴을 분류합니다.**
- 장비가 멈추면 라인이 서고, 라인이 서면 돈이 날아갑니다. **AI가 고장을 미리 예측합니다.**

공정 설계를 맡았습니다.   
"이 공정에서 수율이 왜 떨어지는가?" — 변수가 수백 개입니다.   
사람이 하나씩 바꿔가며 실험하면 몇 달이 걸립니다.   
**AI는 데이터에서 병목을 찾아내고, 수율 0.2%를 올립니다.** 0.2%가 작아 보이지만, 반도체 라인에서 그건 수십억입니다.

이게 남의 이야기가 아닙니다. 우리가 가게 될 회사에서, 우리가 맡게 될 업무에서 벌어지는 일입니다.   
공정을 아는 사람은 많습니다. AI를 아는 사람도 많습니다.   
하지만 **공정도 알고, AI도 아는 사람**은 아직 많지 않습니다.

그래서 우리는 **AI를 쓰는 사람**이 아니라, **AI를 만들고 설계하는 사람**이 되고자 합니다.

## 어떤 내용을 배우는가?

### 1. 데이터 분석 — Pandas

데이터를 다루는 것부터 시작합니다.   
CSV를 불러오고, 결측치를 처리하고, 조건에 맞는 데이터를 필터링하는 것.   
공정 데이터든 측정 데이터든, 일단 데이터를 읽을 줄 알아야 뭘 하든 할 수 있습니다.

### 2. 시각화 — Matplotlib

숫자만으로는 설득이 안 됩니다.   
분포를 보여주고, 추세를 보여주고, 이상치를 눈에 띄게 만드는 것.   
상사에게, 팀에게, 고객에게 — 데이터를 "보이게" 만드는 능력은 어디서든 필요합니다.

### 3. 머신러닝 — Scikit-learn

회귀, 분류, 군집. 고전적이지만 강력한 기법들입니다.   
모델을 학습시키고, 평가하고, 하이퍼파라미터를 조절하는 전체 흐름을 경험합니다.   
딥러닝 전에, 이 기초가 있어야 합니다.

### 4. 딥러닝 — PyTorch

인공신경망의 구조, 순전파, 손실 함수, 역전파, 최적화.   
개념으로만 알던 것들을 코드로 직접 구현합니다.   
단순 회귀 모델부터 시작하여, 실제 데이터에 적용할 수 있는 수준까지 올립니다.

### 5. 이미지 · 오디오 처리

데이터가 항상 숫자 테이블인 것은 아닙니다.   
OpenCV와 torchvision으로 이미지를 전처리하고, Albumentations로 데이터를 증강합니다.   
오디오 데이터는 스펙트로그램으로 변환하여 이미지 기반 분류에 활용합니다.

### 6. 검증

모델이 좋다고 주장하려면 근거가 있어야 합니다.   
Confusion Matrix, F1 Score, Correlation Matrix, mAP.   
이 지표들을 이해하고 활용해야, "이 모델은 신뢰할 수 있습니다"라고 말할 수 있습니다.

## 팀 과제 — 직접 해봤습니다

배운 걸 팀 단위로 직접 적용했습니다.   
데이터를 고르고, 특성을 파악하고, 전처리하고, 모델을 학습시키고, 평가하는 것까지.

| 과제 | 내용 | 핵심 |
|------|------|------|
| 학생 성적 데이터 | 성적에 영향을 주는 요인 분석 및 예측 | 회귀 · 분류 |
| 타이타닉 생존 예측 | 승객 데이터 기반 생존 여부 분류 | 분류 · 전처리 |
| WM811K 웨이퍼 맵 | 반도체 웨이퍼 불량 패턴 분류 | 이미지 분류 · CNN |

결과적으로, **F1 90%**, **mAP@7 0.7** 이상의 신뢰성으로 예측을 성공하였습니다.   
4인 이상 팀으로, 데이터 선정부터 모델 평가까지 전체 파이프라인을 경험했습니다.

## 앞으로의 커리큘럼

아직 가야 할 길이 남아있습니다. 앞으로 이런 방향으로 나아갑니다.

### 고급 딥러닝
- CNN 심화 — ResNet, EfficientNet 등 SOTA 아키텍처 분석 및 구현
- Transfer Learning — 사전학습 모델을 우리 데이터에 맞게 미세조정
- 모델 경량화 — Pruning, Quantization을 통한 엣지 디바이스 배포

### 시계열 · 신호 처리
- RNN, LSTM, Transformer 기반 시계열 예측
- 공정 데이터, 센서 데이터에 대한 이상 탐지

### 실전 프로젝트
- 실제 산업 데이터를 활용한 end-to-end 프로젝트
- 데이터 수집 → 전처리 → 모델링 → 배포까지의 전체 사이클 경험
